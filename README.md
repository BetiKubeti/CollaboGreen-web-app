# CollaboGreen Web App

**CollaboGreen** is a user-centered web application that connects environmentally conscious businesses with potential partners, investors, and users who value sustainability. The platform offers ESG (Environmental, Social, Governance) statistics in an intuitive, visual format, along with detailed company profiles, reviews, and social media links.

Built with a strong emphasis on accessibility and user-friendly design, CollaboGreen streamlines the process of researching, reviewing, and evaluating companies’ sustainability efforts. Key features include interactive search functionality, profile customization, and a dedicated space for user reviews. Designed iteratively with user interviews, affinity diagrams, and testing (Lo-Fi, Mid-Fi, and Hi-Fi stages), CollaboGreen ensures that companies’ sustainability initiatives are transparent and easy to access for all stakeholders.

---

## 🚀 Features

- **Detailed Company Profiles:** Access ESG statistics, descriptions, reviews, and social media links for businesses.
- **Interactive Search:** Easily find companies that align with your sustainability values.
- **User Reviews:** Share your experiences and read reviews from other users.
- **Profile Customization:** Tailor your user profile to reflect your interests and sustainable focus.
- **Visual Data Representation:** Understand complex ESG statistics through clear and intuitive visuals.

---

## 🛠️ Technologies Used

- **React:** For building dynamic and responsive user interfaces.
- **Firebase:** Backend services including authentication, real-time database, and hosting.
- **Vite:** A fast, modern build tool that provides instant hot module reloading and optimized build output.
- **CSS:** For styling and layout.
- **react-firebase-hooks:** Simplifies integration with Firebase services.
